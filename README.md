# ClipForge for Windows

Download the latest installer from [Releases](https://github.com/kamrancreation/clipforge-releases/releases/latest).

ClipForge is a desktop video editor for Windows 10 and 11 (64-bit): timeline editing with layers and keyframes, offline auto captions, AI background removal, 4K/8K GPU export and more.

- Website: https://clipforge-brown.vercel.app
- What's new: https://clipforge-brown.vercel.app/changelog

This repository only hosts installers and the auto-update files the app checks. The installer isn't code-signed yet, so Windows SmartScreen may show a warning: choose **More info → Run anyway**.
